# 实机迁移规划任务摘要

用户要求先审阅按实机迁移思路完成的仿真仓库，通过ssh jetson了解Nano、D435i、PX4，并规划迁移实机方案。允许联网参考资料。本轮请求为规划，不自动执行安装、飞控参数写入或飞行。

约束：立即推进可实施工作、按风险适度验证、修根因避免重复检查、核心流程可用即可交付、常规可逆选择自主完成、允许简化非核心能力、只保留真实边界所需保护。

决定：复用现有Nano/Foxy驱动和同基准VINS来源；独立实机工作区移植本仓库固定代码，保留唯一PX4出口。按H0.1构建/传感器→手持定位建图→满载→拆桨融合→悬停→短目标→避障推进。来源只读，迁入时锁来源及哈希，未将实验接口视为可飞。

待明确：PX4实际固件/板型、真实安装外参与尺寸、基础机体飞行情况、遥控接管与现场场地。它们不妨碍后续先做H0.1。

本文件仅保存任务摘要，不是运行通过证据。方案见docs/hardware-migration-plan-20261102.md。

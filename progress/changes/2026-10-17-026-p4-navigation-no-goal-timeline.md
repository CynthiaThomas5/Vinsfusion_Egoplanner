- 成本拆分：#56 在同样无目标、canonical `/clock` 条件下完成最终重跑；847/847状态样本有效，22个执行器窗口覆盖43.935秒，generator 主线程CPU中位数0.652 s/s，`/clock` ready中位数130.43 Hz。原生 WaitSet 计数269,746次，每32次采样一次，共计时8,429次，样本总计0.410秒 wall／0.053秒线程CPU；不按系统采样外推。订阅与 timer 的 take/callback CPU计时总量较小，但未解释 generator CPU。四个栈快照落在 WaitSet、waitable 插入及 event-handler 退出等不同位置，不能据此认定热点。EGO仍有60条 odom/depth timeout；导航唯一 stale warning 出现在上游 teardown 后。第一次 live instrumentation 因 Python WaitSet proxy 与 C++ ActionServer 类型不兼容而排除；有效重跑移至该 run 的 `retry-1/`，所有失败尝试保留。

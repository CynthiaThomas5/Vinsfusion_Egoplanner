# #071 第3个小目标：检查回环是否降低里程计误差

[授权与范围](../../collaboration/dialogues/2026-10-22-071-loop-drift-evaluation.md)。只分析070-02保留记录；没有修改自维护／第三方源码、配置、依赖、健康门或控制链路。原有未提交改动保留。

新增的离线分析脚本放在原始run目录 `artifacts/runs/real-loop-20261022-070-02/compare_loop_drift.py`，输出同目录的JSON、CSV、PNG和运行日志。比较源是 `fixture-odometry.jsonl` 中VINS原始位姿，以及 `loop-observation.json` 中观察器记录的 `loop_<epoch>_map` 后端修正位姿；不把另一个 `kind=optimized` 的VINS适配流当作回环修正。仅选取两路共有的精确源时间戳，5,065个对齐后样本全部配对。真值使用源时间插值（最大括距20ms）和SDF模型到IMU外参。

在fixture初始静止段，用单个源时间50.624s的原始VINS pose对Gazebo IMU真值做一个刚体对齐，尺度固定为1；把同一旋转和平移原样用于两条轨迹，不在任一回环后重对齐。首次回环前3,993个样本两路位置坐标最大差为0，姿态最大差约1.2e-6度，支持该共同坐标比较。对raw→loop输出变换的离散跃迁也进行独立提取，两个变换变化分别出现在642.644s／691.088s，落后已验证回环关键帧源时间1.252s／0.724s。

结果：整个746.592仿真秒共同记录上的位置RMSE由6.096cm降至4.255cm（30.2%），yaw RMSE由0.687度降至0.674度（1.9%）。首次修正后至第二次修正期间，位置RMSE由9.174cm降至2.751cm（70.0%）；第二次修正后106.128秒内由10.185cm降至2.587cm（74.6%）。每轮返航稳定驻留最后10秒的cycle 6／7位置RMSE分别由9.27／11.58cm降至2.87／3.26cm；yaw仅由0.969／1.222度降至0.950／1.177度。末帧位置误差10.64cm降至2.32cm，但末帧yaw误差仍有1.07度。

复算命令 `python3 artifacts/runs/real-loop-20261022-070-02/compare_loop_drift.py` 退出码0。报告JSON／证据JSON解析成功，逐一复核分析脚本、原始输入和输出图表／CSV的SHA-256通过；`git diff --check`通过。此轮是原记录离线分析，没有改代码，因此未重跑软件测试或构建。正式P0–P6／S1–S6里程碑未升级。

结论限于一个理想仿真场景的一次unarmed支架轨迹：在本次已记录数据上，回环修正明显降低位置误差；航向只略有改善，仍有约1.18度残差。它不证明多次运行可重复、自由飞行安全、修正能无缝接入定位控制，也不证明零漂移。下一小目标建议以相同诊断配置另开fresh epoch重复轨迹，验证真实回环和位置／yaw改变量是否重现，待用户批准后实施。

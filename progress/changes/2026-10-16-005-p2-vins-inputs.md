# P2 模型配置、静置初始化与动态漂移复现

对应[对话摘要](../../collaboration/dialogues/2026-10-16-005-p2-vins-inputs.md)。

## 修改

- config/components/localization/vins_sim.json 保存非几何参数；正的 IMU 噪声是理想仿真的求解权重，并非实测相机噪声或已冻结验收阈值。
- tools/generate_vins_config.py 从 SDF 生成左右相机内参和相对相机 IMU 的外参，生成独立 epoch／raw namespace／frame，保存配置哈希，拒绝覆盖已有会话。
- sensors.launch.py 接受实际 world 路径，默认仍为静态校准世界。
- tools/prepare_motion_world.py 从同一模型与校准场景生成 debug 运动世界；解除固定支架，关闭该校准刚体重力，以 Gazebo VelocityControl 激励。模型位姿只进入 Gazebo 的隔离记录器，不桥接进在线 ROS 定位链。
- tools/run_sensor_motion.py 按仿真时钟发送有界、平滑的三轴速度与 yaw 角速度；记录相机 IMU 及真值，不使用真值控制，不发布 PX4 指令。
- tools/probe_vins.py 只读保存优化／传播输出、原始 stamp 和求解遥测。
- tools/evaluate_vins_motion.py 使用一次 SE(3)、固定尺度 1 评估，与真值插值配对；不重写 stamp，不分段对齐。
- 相应测试覆盖配置哈希／拒绝覆盖／IMU 杆臂、运动边界／单刚体、刚体对齐及拒绝以缩放／反射消除误差。

## 实际验证

- python3 tools/test_vins_config.py：2 项通过。
- Gazebo 容器中 test_motion_tools.py：2 项通过；test_vins_alignment.py：3 项通过（含坏真值时间戳拒绝）。
- uav_sim 修改后实际 colcon 构建成功，日志在 artifacts/runs/p2-vins-motion-20261016/build.log。
- 静态运行 p2-vins-static-20261016：自然初始化完成，314 个优化输出、4130 个传播输出、314 条 initialized 遥测；优化约 15.15 Hz，传播 200 Hz，位置最大范数 0.00285 m。只证明该理想场景的一次静置初始化与有限值输出。
- 首次动态运行 p2-vins-motion-20261016：真值记录误读 Pose_V 外层空 stamp，记录不可用于精度；Gazebo Python 活跃订阅在解释器退出时引发 exit 134。保留记录，修复为各 Pose 的 stamp，并在退出前主动 unsubscribe。
- 重新冷启动 p2-vins-motion-retry-20261016：记录器 exit 0，2500 个真值与5001个 IMU 样本；三轴运动跨度约 0.192/0.265/0.131 m、yaw 约 21.2°。优化576个、传播7592个；相同时间重叠中373个位姿，单 SE(3) 位置 RMSE **0.900 m**，最大误差1.527 m，动态定位不能通过预验收。非正式冻结测试，不据此放宽阈值。
- 同一运动中，IMU 相对真值导数的比力 RMSE 约0.037 m/s²、yaw 角速度 RMSE 约0.00021 rad/s；这只是初步一致性测量，差分与采样误差尚需分析。
- initialized 和 solver_usable 在明显漂移时仍为 true，最终加计偏置范数约0.330 m/s²、final_cost 约19891。源码 failureDetection() 开头直接 return false，健康门控尚未实现；不擅自把其余旧阈值启用当作根因修复。

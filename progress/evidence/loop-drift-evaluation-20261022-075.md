# #075：074-02回环漂移比较

**结论：**在这次fresh epoch未武装支架路线中，4次loop_fusion优化显著降低了位置误差，但仍留有位置与航向误差；结果不构成长期不漂保证、飞行验收或控制接入依据。

## 方法

只分析[运行`real-loop-20261022-074-02`](../../artifacts/runs/real-loop-20261022-074-02/)。比较源是`fixture-odometry.jsonl`中的`kind=raw`和[loop observer实际输出](../../artifacts/runs/real-loop-20261022-074-02/loop-observation.json)中的`odometry`，不把另一路`kind=optimized`流当作回环结果。epoch为`d612f794c58d4c898a03adcc1d7603b0`；原始VINS frame和loop map frame身份一致且各自固定。

沿用#071／#072方法：使用起始静止保持段中一个raw VINS源时间位姿，对齐到独立Gazebo IMU真值；只应用一次刚体旋转和平移，尺度固定1。相同变换用于raw和loop输出，回环后不重对齐。锚点源时间37.424秒，起始静止段自36.532秒开始。真值只用于离线评估。

两条里程计按完全相同源戳配对。对齐后4,586对样本覆盖747.384仿真秒，raw覆盖率100%；最大真值插值括距20ms。首个测得raw→corrected姿态变化发生在525.496秒，距第一条验证边5→63当前关键帧0.332秒。全记录测到4个姿态变换阶跃，与4条经独立检查的验证边对应。位置和yaw使用同一组样本计算样本RMSE；时间加权RMSE按相邻源戳梯形积分，排除间隔大于200ms的区间。

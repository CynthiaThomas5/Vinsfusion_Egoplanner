## 变换契约

定位输入保留相机IMU参考点，姿态 `R_WI`，线速度/角速度均为IMU体轴分量。不能将硬件IMU optical轴当作仿真FLU。`T_BI=[R_BI,t_BI]`将IMU坐标映射到约定机体FRD，`t_BI`为机体原点到IMU的机体系向量。

```text
R_WB = R_WI R_BI^T
p_WB = p_WI - R_WB t_BI
omega_B = R_BI omega_I
v_B = R_BI v_I - omega_B × t_BI
```

桥内先完成上述参考点变换，再复用现有坐标转换。输出位姿使用PX4 `POSE_FRAME_FRD=2`：重力对齐、Z向下、任意恒定初始航向；它不是True North NED。速度/角速度是BODY_FRD。到真实PX4 local的yaw/原点配准以及规划参考点转换仍由未完成的HW08.3负责，硬件control不会绕过它。

非零杆臂算例：`t_BI=(.20,.01,0)m`、`R_BI=I`、`omega=(0,0,1)rad/s`、IMU点速度 `(-.01,.20,0)m/s`，转换后机体原点速度为0；另有90度pitch杆臂、正前/左/上、180度旋转和非法反射矩阵检查。算例为解析测试，不是当前真实安装外参。

现有planner只提供yaw/yaw_dot，其位置/速度杆臂处理仍是低倾角近似，缺完整姿态/角加速度。已加限制注释，未声称所有加速度参考点严格等价；需要最终安装后的地面误差量测。HW07原参数备份中EKF2_EV_POS_X/Y/Z与EKF2_IMU_POS_X/Y/Z均0，本轮不改参数；实际启用机体EV前需再次回读，避免桥内与PX4重复补偿。

## 时间契约与真实记录对照

HW07证明实际PX41.17.0的`SYNCT=1/SYNCC=0`。Agent在Nano进程，ROS硬件source stamp已在同一Nano系统epoch；monotonic仅测本机间隔和系统钟变化，PX4 HRT由协议反序列化恢复。

- `timestamp_sample = original_source_ns // 1000`。
- `timestamp = system_ns_at_send // 1000`。
- 不将负的Timesync estimated_offset再加到上述输出。offset仅用于验证恢复HRT为正；actual `source_protocol=2`、RTT/源龄/接收龄均要合格。
- 硬件不订阅`/clock`，要求use_sim_time=false；系统/monotonic漂移或倒退超过显式预算会锁定，必须重建会话。epoch切换也锁定，未拼接新旧会话。
- 源龄与接收龄单独显示。源龄预算复用HW04 optimized 0.868306s；Timesync 2s覆盖HW07实际约1Hz更新，不冒充10Hz。时钟跳变预算50ms、future预算20ms及方差均是候选配置，没有扩大HW04定位门限或获得完整负载资格。

8项新测试包括已知50ms采样延迟、未来/陈旧source、错误Timesync协议、系统钟跳变锁定，以及对HW07 **60条原始Timesync**逐条代入真实系统/monotonic/offset。Nano旧日历原样保留，没有跨主机直接减stamp，也没有重跑USB协议切换。

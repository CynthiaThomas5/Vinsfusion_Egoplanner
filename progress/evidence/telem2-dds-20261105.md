# TELEM2独立DDS只读验证

范围：用户自行配置TELEM2→Nano，要求查看消息。只启动只读Agent/观察器与被动波特率采样；未改PX4参数、未重启、未发EV/控制。

## 结果

Nano开机后ssh jetson成功（此前No route为未开机），CH340 1a86:7523位于/dev/ttyUSB0，内核4.9.337-tegra。现有项目px4_dds.json仍为历史USB临时切换方案，未作为新TELEM2参数来源，后续不能直接套用旧USB切换入口。

Agent serial /dev/ttyUSB0 -b921600 -v6 +独立ROS环境只读record_hw10_ev.py观察20s，观察器定时器正常、退出0，DDS计数空；Agent无会话建立日志，进程均已停，串口无占用。

被动扫描常见波特率及约1M细分：有持续字节，接近1M时出现重复XRCE式报文结构，但帧头/数据字节存在错误，没有取得完整有效握手；个别7e前缀不当作成功。不得将有字节误报接通或对原始字节作纠错后冒充真实遥测。

用户USB同时接Codex本机后，应用26ac:0032成功枚举。probe_hw07_px4.py退出0，实际FMUv5/V5006000、PX41.17.0 d6f12ad1...，1101/1101公开参数完整。参数：SER_TEL2_BAUD921600、UXRCE_DDS_CFG102、DOM_ID0、KEY1、SYNCT1/SYNCC0；MAV_1_CONFIG0（TELEM2 MAVLink已禁用）；MAV_0_CONFIG101，SYS_USB_AUTO2。

只读NSH dmesg实际启动：Starting UXRCE-DDS Client on /dev/ttyS2；init serial /dev/ttyS2 @921600。status为Running disconnected、timesync false。不存在/fs/microsd/etc/extras.txt。USB MAVLink另在ttyACM0，故此状态不属于同端口两协议争用。

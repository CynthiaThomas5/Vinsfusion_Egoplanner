# 导航纹理

从#051三连通过场景保存的确定性灰度PNG，原生成器seed417、1024×1024、地面128格／障碍16格、灰度35/75/125/180/225。资源只影响视觉纹理，场景生成器验证物理碰撞未变。


## 多柱场景自然材质

`natural_terrazzo.png`用于pillars场景40×40m地面上的8m平铺纹理，旨在提供适合相机跟踪的细节并避免棋盘格。材质为本地生成的固定albedo；原始提示词、生成记录和SHA256见`natural_terrazzo.json`。柱体使用场景配置中的蓝绿实体色和浅色窄装饰带，装饰带仅视觉，碰撞轮廓仍由原柱体形状决定。

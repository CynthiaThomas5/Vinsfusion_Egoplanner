# N11批准后的离线队列校准（#481）

#478–#480已证明，IMU消费前缓存包含当前积分区间及未来IMU；有限窗口OLS正斜率不能单独证明积压。用户明确批准重校准。旧revision8及其FAIL原样保留，缺新增字段的归档为INSUFFICIENT，不补造字段或倒算正式次数。

0021只读补丁在既有互斥区读取当前项之后的等待特征数、特征首尾源跨度、当前积分终点、最新已到IMU及消费后最早IMU。原始计数、高水位、OLS仍输出。生产BEST_EFFORT输入、求解、队列容量/丢弃/控制均不变；该记录有实际开销，由新候选完整运行检验。

预声明草案：源跨度和最新IMU相对积分终点的滞后不超过0.2sim秒；30Hz双目/stride2即15Hz处理，当前项之后最多2个等待项。0.2秒保留原生EGO0.4秒超时的一半时间余量；这是SITL支持负载的离线性能预算，不是控制保证或实机认证。消费后不得残留早于积分终点的IMU。逐项序号连续、源时间严格前进、相邻观察源间隔不超过0.2秒，覆盖PRESTREAM至落地；否则不足。失败优先于缺数据，真实预算越界仍FAIL。

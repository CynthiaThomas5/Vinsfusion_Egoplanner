## 1. 完成范围与已有基础

普通任务的正常序列为：起飞并稳定 → 一个机头前向 EGO 目标 → 实际到达／停车保持 → 结束导航目标 → 独立发起降落收尾并确认 landed/disarmed。到达不自动返航；降落是本次试验安全收尾，不是普通导航 action 的隐含动作。

## 3. A：先补试验工具与终点降落前提

### 3.1 单目标判定

修改对象以 `tools/run_n08_braking_trial.py`、`tools/debug_truth/evaluate_n08_braking.py` 及专用 goal 配置为主。保留专用返航场景供后续独立使用，为普通单目标提供明确模式，默认不发送转向／home action。

记录并分别判定：准入 → 起飞稳定 → 首个目标接受／样条执行 → 实际到达 → 末端停车保持 → 降落收尾 → landed/disarmed。只有首目标数据不能把全流程判 PASS；只有返航字段缺失也不能使合法单目标判 FAIL。

回放测试用 #260/#267/#273 原始输入生成新的单目标分段审计报告，明确版本／区间／缺失证据；不覆盖原运行文件，不把分段成功自动计入同版本完整资格。针对性组件验证覆盖：真实目标失败不能通过、缺少停车或 landed 证据不能通过、单目标不要求返航、旧往返场景仍保留自己的判据。

### 3.2 终点降落

当前 runner 的正常降落计划依赖返回原 N05 pad。改成终点收尾后，原 pad 的准入不能证明终点下降体积和接触区域可用。#260 的终点附近安全落地是结果记录，也不能倒推当时已有目标落地区准入。

先审计原始 raw map 能否覆盖候选终点及误差余量内的下降体积、地面和允许接触区域；实施前建立同 run 的终点降落候选几何检查，并在降落前更新。沿途可能中止的位置也应有预先说明的退出区域，避免只验证终点。

复用 N05 的机体、地面拟合、体素分类和相交规则，区分“候选地面几何”与“飞机已落地状态”。不得把空中／未来目标伪装成 landed，或调用旧接口时人为设置 `ground_confirmed=True` 获得地下豁免。需要新增候选下降检查时，属于 N08 必要实现，保留真实触地阶段规则并回归受影响的 N05 项。

没有合法下降／接触证据时，单目标飞行尚未准备好，先补 raw 深度观测或检查实现；不恢复自动返航来掩盖该缺口，也不以世界地图代替在线证书。

## 4. B：回答“为什么接入 EGO 后飞机会这样运动”

对照三种方式，统一声明坐标、传感器参考点、初始稳定条件、运行负载及有效版本差异：

1. 固定 hold：没有 EGO 目标／执行命令，量化自然保持漂移，作为基线。
2. Compute-only：相同目标和规划参数，EGO 生成曲线，bridge 输入与曲线隔离并保持原位置；确认计算、地图查询本身未改变 PX4 参考。
3. Native execute：相同几何、目标和速度配置，bridge 接收真实曲线；逐层解释参考变化与独立运动。

首先审计已有数据是否足以闭合这三条因果链。#212 与 #257 并非完全相同有效版本，必须记录差异及其影响；若旧基线无法代表修复后的控制行为，才补对应一个基线，不重做 N07 三次悬停。

统一时间线记录：目标请求／接受、样条 start stamp／traj_id、PositionCommand 源戳与接收戳、PX4 setpoint 时间／位置／yaw、PX4 反馈、VINS 与独立真值。分别核对首样本切换和每次重规划的左右极限、位置／速度／yaw 与 yaw wrap、过期参考／COMPLETED 处理。

当前 bridge 是位置控制，PX4 setpoint 的速度和加速度为 NaN；EGO 的速度／加速度字段用于参考分析，不能直接认作 PX4 速度前馈。用同一 SE(3)、scale=1、起飞前固定对齐分析所有分层，不在飞行后拟合掉跟踪误差。杆臂补偿按当前相机 IMU 参考点与 base_link 真实外参转换。

对没有既定数值界的切换量，先报告测量、采样误差及其相对既有轨迹／空间预算的影响；不得凭本轮成功值反推出新阈值。缺少可执行判据时，在冻结前给出来源与建议，原出口保持未完成。

## 5. C：正常末端停车测量

### 5.1 保持已有试验速度

沿用 `n08_low_speed_trial.json` 的逐轴 `max_vel=0.10 m/s`、`max_acc=0.25 m/s²`，前向 0.6 m、高度和 yaw 不变。已有实际曲线和飞机速度峰值约 0.081 m/s，有真实运动与制动信号，继续用它收敛证据。不额外围绕 0.075 m/s 反复调参，也不新增高速度／长航程扫描。

以下不同含义在冻结前必须写清并由一致的判断器执行：

### 5.2 单次步骤

1. 全新仿真／PX4／VINS 会话，记录 epoch、map_id、实际参数和源码／binary／环境哈希；确认唯一 bridge、在线无真值／完整世界地图。
2. 复用已验证的未武装扫描路径；支架移除后和 mission 前分别取得本 run 新鲜 N05 准入。检查前向运动、停止／保持及降落区域，不复用旧快照。
3. 运行已有只读 preflight，enable 后等待 ACTIVE 和稳定门；删除无用途高负载点云 observer，必要轻量记录器固定版本／频率。
4. 发一个前方 0.6 m 目标。在线核对每条最终曲线的身份、时间、动力学、完整扫掠、末端保持与连续管道；检查实际参考跟随、速度、健康和地图连续性。
5. 目标返回成功后保持至少 3 仿真秒，独立确认停车和停后位移；结束导航任务，完成经检查的目标区降落，实际 landed/disarmed 后停止项目会话。

### 5.3 每次必须输出

- 参考／实际三维速度、沿航向速度、位置、跟踪误差、加速度曲线，并标注参考开始减速、实际持续减速、阈值停车、到达、保持和降落时刻。
- 参考减速开始到实际停车的路径长度、前向净位移、参考零速后的残余位移；不把总停车路径长度等同于越过终点的距离。
- 停车定义沿用水平速度 ≤0.03 m/s、垂速绝对值 ≤0.05 m/s 持续 1 s；另报停止保持期间的位置变化，不能宣称精确零速。
- 响应时间、有效减速区间与样本数、减速度分布、最大独立跟踪误差。已有 0.22 s 对称平滑会影响响应起点；保留原始数据，报告滤波／配对／采样误差。
- 将传输／调度延迟与“实际达到持续减速判据的时差”分开。历史 0.112–1.412 s 不能直接当纯通信延迟范围。

## 6. D：运动中取消，先解决功能再飞

### 6.1 当前缺口有源码依据

当前 `TrajectoryCancel` 只有 `MODE_ABORT`。navigation 的 caller cancel 发布该模式；traj_server 清轨迹并输出 ABORT；bridge 将 ABORT 标记为 trajectory fault；ACTIVE 状态机据此进入 LANDING。因此当前不是已经实现“正常取消后在空中受控制动并保持”。Compute-only 的取消发生在桥保持时，也不证明运动取消可行。

先用隔离集成／回放把 action result、取消消息、EGO／traj_server、bridge 状态串起来。若要满足取消后停止／保持，实施方向是区分正常用户取消与健康／地图／定位故障中止，提供可验证的停止→保持交接；故障仍沿原有退出政策处理。具体接口在实现审计后确定，不能仅清 fault、屏蔽 ABORT 或持续发布旧设定点。

停止轨迹仍须满足同身份 fresh raw-map 全曲线、动力学和 terminal-hold 检查，控制仍由 bridge 独占。不能由 bridge 临时拼一段未经认证的平滑曲线。若修改 vendor EGO／traj_server，保存基准、补丁顺序／哈希并构建相关包，补跨接口集成验证。

### 6.2 实测前的空间前提

另立取消校准协议。现有 `planned_terminal_stop` 协议明确不覆盖任意运动取消；需要专门的触发条件、停止边界、失败收尾和记录字段。不能在旧 runner 上随意按取消键就算完成测试。

在首个取消动作前，先从已有控制链证据、隔离仿真及保守计算，给出覆盖停止和故障退出的有限边界，再检查真实 raw-known-free 区域。已有约 0.30 m 是正常规划末端制动结果，不能直接作为突然取消的停止上界；0.25 m tracking margin 也不是取消制动距离。边界尚不成立则不执行该动作，先补控制链／退出边界证据。

### 6.3 建议试验流程

1. 先在较低但明显非零、且高于 0.03 m/s 停车阈值的速度窗口取消；建议首个触发窗口 0.04–0.06 m/s，属于待实现的实验设置，不是新增完成阈值。
2. 由参考与实际 PX4／VIO 反馈共同确认正在前向运动，且尚未进入原曲线末端减速；用确定事件触发取消，不使用固定墙钟 sleep，也不使用真值控制触发。
3. 记录请求发出、服务／action 接受、旧轨迹失效、停止曲线接管、实际减速、停车／保持时刻。量测从取消请求及从停止参考生效开始的两种距离／时间。
4. 验证 action 的取消终态、实际停止／保持和不再执行旧 goal 三项分别成立。迟到旧样条／旧 goal／旧 epoch 拒绝先在隔离测试覆盖，避免为此重复飞行。
5. 首次成功并回填预算后，再在接近已选实际峰值约 0.08 m/s 处重复，覆盖当前试验速度。保持既定空间和速度门，不扩大到任意速度／任意方向。
6. 若进入 LANDING，保留安全退出证据，但取消后空中保持仍未通过；若未触发取消、取消时已经自然停车或数据缺失，记录为无有效取消测量，不算成功。

## 7. E：同版本至少三次独立冷启动

A–D 及 F 初版回填涉及的必要控制／接口／准入修复完成后，再固定 N08 候选版本，避免在三次重复之间继续改运行逻辑。此为 N08 运行身份锁定，不代替 N10 的最终干净重建／统一版本验收。

冻结有效源码、依赖补丁、实际 install binary、配置／模型、PX4 参数、镜像、launch、runner、在线 watchdog、离线 evaluator 及 observer 配置。每次查 manifest 与实际参数，防止再次漏传 planner profile。

至少三次分别启动全新 PX4、VINS epoch、地图和任务会话，执行同一正常单目标协议。每次同时满足：合法准入／几何，参考和健康连续，真实位移与到达，末端停车／保持，合法降落 landed/disarmed，唯一 bridge，在线无真值辅助，所有适用速度／跟踪／时间门通过。

N08 条款要求独立三次，未要求连续；同一有效版本已通过的 run 累计保留，失败不抹掉已通过记录。与执行结果无关的文档改动不使次数清零。影响定位、地图、控制、取消、有效配置或试验逻辑的修复必须先审计影响范围，只对受影响的资格重建证据。N07 已通过三次不重复。

每次若只在起飞前被准入拒绝，则留为前置拒绝；若起飞后健康／参考／真实运动失败，则留为运行失败。二者都不能计入三次成功。没有变化的同一阻塞不反复重启；下一次必须有新证据和明确主要变量。

## 8. F：把测量变成 N05／N06 真正使用的预算

区分正常末端制动与正常取消制动两个行为范围，分别汇总速度、响应、停止距离、残余漂移、跟踪、定位／地图／体素／采样误差及观测龄。避免将同一定位误差在地图半径、跟踪余量和停止距离中重复相加。

在可证明响应上界与减速度下界适用时，可用诊断模型：

`d_stop(v) = v × tau + v² / (2 × a_min)`

其中 tau 必须覆盖实际制动动作前的有关延迟，a_min 必须有对应速度／运动方式的依据。现有减速度 p10 是有限样本分位值，不是已保证的 a_min；PX4 最大加速度参数也不是下界。测得的停车路径若已包含响应段，比较／组合时不能再次机械加入同一 v×tau。

对本次速度范围，给出有限仿真样本的保守经验包络、测量不确定度和支持范围；如数据不足以支持运行所需边界，保持该出口未完成并补对应测量，不伪造任意速度公式。
